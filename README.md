# 受付スキャナ

公演ポータル (ls-portal) の当日受付で使う QR スキャナです。カメラを開きっぱなしにして、お客様の QR を自動で連続読み取りし、公演ポータルへ入場処理を送ります。

- 公演ポータルの「入場管理 → QRスキャナ」(または「📱 スタッフ端末の登録」) から開きます (`#api=...&id=...&k=...` 付き)。
- 公演と受付スタッフのキーは、その端末のブラウザにだけ保存します。このリポジトリには予約データ・キーを含みません。
- 入場処理は公演ポータルの `doPost` (`action: 'staffScan'`) が受付スタッフのキーを確かめて行います。
- Google Apps Script のページの中ではカメラを使えない (ページの枠がカメラを許可していない) ため、スキャナだけをここに置いています。
